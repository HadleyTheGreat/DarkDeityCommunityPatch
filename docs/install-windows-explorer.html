File Explorer Installation (Steam/Windows version)

Install steps:

  1. Download the latest Windows version of the the patch package from the bottom of the page at https://www.github.com/HadleyTheGreat/DarkDeityCommunityPatch/releases/latest with your web-browser.
  2. In the Windows file explorer, locate the file you downloaded, right-click it then click on Extract All. Extract it somewhere the user has read, write, and execute access, such as a subfolder of the Documents, Downloads, or Desktop folders.
  3. In the Windows file explorer, navigate into the folder that you extracted the files.
  4. Right-click on the file named APPLYPATCH.BAT (or just APPLYPATCH if you don't show file extensions) and select Open. If you have default Windows security settings, Windows will warn you that you are about to execute a script file and ask you for permission. You must grant it permissions to do the patch installation.
  5. Once the installation is complete, you will have no more need for the zip file you downloaded or the folder you extracted and you can safely delete them by right-clicking them in the file explorer and selecting Delete.
