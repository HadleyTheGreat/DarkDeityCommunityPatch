Command-Line Installation (Windows Versions)

By default PowerShell does not have permission to execute scripts on Windows end-user machines. To open a PowerShell window with appropriate permissions for this install session only, hold down the Windows key and press R, then type: 

powershell -ep bypass

Powershell install steps:

  1. Make a work directory somewhere the user has read, write, and execute permissions and change into that directory 
    2. md Desktop\ddcp
cd Desktop\ddcp
  2. Fetch the install zip file for Windows versions from GitHub. 
    3. curl.exe https://github.com/HadleyTheGreat/DarkDeityCommunityPatch/releases/download/3.0.0/DarkDeityCommunityPatch-Windows-3.0.0.zip -o patch.zip
  3. Extract the zip file into a directory, then change into it. 
    4. md patch
tar -xf patch.zip -C patch
cd patch
  4. Run the patch tool with the --install or -i switch.

    5. Steam version (automatically located directory):

    .\patchtool -i

    Epic Games Store version (manually specified directory):

    .\patchtool -i "C:\Program Files\Epic Games\Dark Deity"

    GOG Galaxy version (manually specified directory):

    .\patchtool -i "C:\Program Files (x86)\GOG Galaxy\Games\Dark Deity"
  5. If all was successful it should have installed the Dark Deity community patch into Dark Deity. Now you can change back out of the work directory and remove it to clean up, as it is no longer needed. 
    6. cd ..\..
rm -r ddcp
  6. And finally you can shut down PowerShell by closing the window or sending the exit command. 
    7. exit
